# Зала Aurea — уебсайт на зала под наем за партита и тържества

Статичен, напълно адаптивен (mobile-first) сайт за банкетна зала под наем с онлайн
проверка на свободни дати и форма за запитване. Без билд стъпка и без зависимости —
отваря се директно в браузър.

## Файлова структура

```
├── index.html      # цялото съдържание и структура (една страница, 10 секции)
├── style.css       # дизайн система, layout, анимации
├── script.js       # календар, планер, галерия, слайдер, валидация на формата
├── DESIGN.md       # дизайн концепция и wireframe
└── assets/img/     # тук се качват реалните снимки (виж по-долу)
```

## Стартиране

Двоен клик върху `index.html`, или локален сървър:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## Секции

1. **Hero** — пълноекранно изображение с ken-burns ефект, заглавие, два CTA бутона
2. **За залата** — снимки, анимирани броячи (600 м², 250/350 места, 80 паркоместа), оборудване
3. **Видове събития** — сватби, рождени дни, корпоративни, кръщенета, абитуриентски
4. **Пакети и цени** — 4 пакета с превключване между тарифа „на час“ и „цял ден“
5. **План на залата** — интерактивна SVG схема: 4 подредби × плъзгач за брой гости
6. **Галерия** — филтрируема по тип събитие + lightbox + видео тур
7. **Отзиви** — автоматичен слайдер със звезден рейтинг
8. **Резервация** — календар с наличност + форма за запитване + 4-стъпков процес
9. **ЧЗВ** — капаро, отказ, външна храна и алкохол, работно време
10. **Партньори и контакти** — Google Maps, телефон, имейл, социални мрежи

## Снимки

Сайтът работи и без снимки: липсващо изображение автоматично се заменя с елегантен
градиентен заместител, който показва текста от `alt` атрибута (`script.js`, модул 1).
За реални снимки качи файловете в `assets/img/` със следните имена:

| Файл | Препоръчителен размер | Къде се използва |
|---|---|---|
| `hero.jpg` | 1920×1080 | Hero секция |
| `hall-1.jpg` | 900×1200 | За залата — вертикална |
| `hall-2.jpg`, `hall-3.jpg` | 900×600 | За залата — сцена и бар |
| `event-wedding.jpg`, `event-birthday.jpg`, `event-corporate.jpg`, `event-baptism.jpg`, `event-prom.jpg` | 800×600 | Карти по тип събитие |
| `gal-1.jpg` … `gal-9.jpg` | 800×600 (широките 1200×600) | Галерия |
| `tour-cover.jpg` | 1200×675 | Корица на видео обиколката |
| `rev-1.jpg` … `rev-4.jpg` | 120×120 | Аватари в отзивите |

Препоръка: WebP/AVIF при качество ~75, максимална ширина 1920 px. Всички снимки под
първия екран вече са с `loading="lazy"` и зададени `width`/`height` (без layout shift).

## Свързване с бекенд

**Наличност в календара** — `script.js`, модул 12. Демо данните се генерират локално.
Замени обекта `availability` с резултат от API:

```js
const availability = await fetch('/api/availability?from=2026-09&to=2027-09').then(r => r.json());
// очакван формат: { "2026-09-19": "busy", "2026-09-26": "hold" }
```

**Изпращане на запитване** — `script.js`, модул 14. В демо режим запитването се пази в
`localStorage` (ключ `aurea_inquiries`). За реален бекенд разкоментирай `fetch` заявката:

```js
await fetch('/api/inquiry', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
});
```

**Видео обиколка** — добави `data-video="https://www.youtube.com/embed/VIDEO_ID?autoplay=1"`
на бутона `#tourPlay` в `index.html` и той ще зареди iframe при клик.

## Достъпност и SEO

- Семантична структура (`header`/`main`/`section`/`footer`), един `h1`, йерархия h2–h3
- Skip link, видим focus, ARIA етикети на календара, слайдера и lightbox-а
- Пълна навигация с клавиатура; Escape затваря менюто и lightbox-а
- Контраст на текста над AA (кремаво #F4EFE6 върху въглено #0E0D0F)
- `prefers-reduced-motion` изключва всички анимации, включително автоплея на слайдера
- Meta description, Open Graph, Twitter card и JSON-LD `EventVenue` schema
- Alt текстове на всички снимки, описателни `title`/`desc` на SVG плана

## Браузъри

Chrome, Edge, Firefox, Safari (последни 2 версии) и мобилни браузъри. Използват се
CSS Grid, custom properties, `IntersectionObserver` и `scroll-snap` — всички с широка
поддръжка. Без анимации сайтът остава напълно функционален и в по-стари браузъри.
