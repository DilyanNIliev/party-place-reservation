# Дизайн концепция — Зала Aurea

## Идея

Луксозна вечерна атмосфера: тъмна основа, върху която снимките на залата светят като
осветена сцена. Златото се използва пестеливо — само за акценти, цени и призиви към
действие, така че да води окото към бутона „Провери свободни дати“.

## Цветова схема

| Роля | Цвят | Код |
|---|---|---|
| Основен фон | въглено черно | `#0E0D0F` |
| Вторичен фон (редуващи се секции) | по-топло черно | `#17151A` |
| Картички и полета | графит | `#201D24` |
| Акцент | шампанско злато | `#C8A24A` |
| Акцент светъл | светло злато | `#E3C87F` |
| Втори акцент | бордо | `#6E1B2E` |
| Текст | кремаво | `#F4EFE6` |
| Второстепенен текст | сиво-бежово | `#9A9289` |
| Статуси | свободно `#7BC47F` · опция `#E8B23A` · заето `#E0705F` |

Контрастът кремаво върху въглено е 15.8:1 — над изискването AAA.

## Типография

- **Заглавия:** Playfair Display 600, tight tracking, курсив за акцентни думи
- **Текст:** Manrope 300/400/600, line-height 1.7
- **Надзаглавия (eyebrow):** Manrope 600, uppercase, letter-spacing .22em, злато
- Скала с `clamp()` — плавно мащабиране от 360 px до 1440 px без media queries

## Мобилна адаптация (< 980 px)

- Навигацията става падащо меню от хамбургер, с блокиран скрол на body
- Всички решетки колабират в една колона; `auto-fit minmax()` прави прехода без чупене
- Календарът остава 7 колони с квадратни клетки (`aspect-ratio: 1`)
- Избор на дата скролва автоматично към формата
- Слайдерът с отзиви преминава на 1 карта с scroll-snap и жест за плъзгане
- Плаващите бутони WhatsApp/Viber остават достъпни с палец

## Движение

| Ефект | Къде | Времетраене |
|---|---|---|
| Ken Burns | hero изображение | 26 s, редуващ се |
| Reveal при скрол | всички секции, с каскада 90 ms | 700 ms |
| Брояч | статистиките за залата | 1.4 s, ease-out cubic |
| Hover lift | карти, пакети, бутони | 250–350 ms |
| Пулсиращ бутон | ▶ на видео обиколката | 2.4 s безкрайно |

Всичко се изключва при `prefers-reduced-motion: reduce`.
