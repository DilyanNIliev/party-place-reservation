# Снимки

Тази папка е празна нарочно. Сайтът показва елегантен градиентен заместител на мястото
на всяка липсваща снимка, така че да работи и преди да качиш реалната фотография.

Имената на файловете и препоръчителните размери са описани в главния `README.md`,
раздел „Снимки“. Формат: WebP или JPG, качество ~75, максимална ширина 1920 px.
